Teste rápido no celular

  1. Configure no WAHA/AstraCalls a URL do cliente acima (evento message; opcional message.any para detectar o atendente).
  2. De qualquer celular, envie /lobo-sales-agent Olá para o número conectado — isso libera uma sessão de teste de 30 min só para aquele contato.
  3. Ou libere seu número em Segurança & Conexões (whitelist). Para recomeçar do zero, envie /reset.
Mensagens normais de clientes reais são ignoradas em silêncio enquanto o Sandbox estiver ativo.
